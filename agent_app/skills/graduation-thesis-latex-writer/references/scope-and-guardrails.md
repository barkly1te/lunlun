# Scope Control and Hard Guardrails

Read this file for:

- page-count control
- directory compression
- rollback to an earlier structure
- chapter-by-chapter refinement
- TOC formatting tasks

## 1. Stage recognition

Decide the current task before producing output:

- outline only
- page planning only
- directory adjustment only
- TOC formatting only
- single chapter or subsection writing
- writing inside a confirmed directory
- compression or rollback
- explicit end-to-end continuation

If the phase is unclear, stay conservative.

## 2. Page-count gate

Before writing thesis body text, confirm:

- body page count or page range
- whether appendices count as body pages
- whether references count as body pages
- whether acknowledgements count as body pages

If this is still unclear, stop at outline, page planning, directory advice, or chapter responsibilities.

Do not expand the thesis body yet.

This hard gate applies to chapter drafting and body expansion. It does not block local proofreading, sentence polishing, or paragraph-level revision of user-provided text.

## 3. Directory freeze

Once the user confirms the `chapter / section / subsection` structure, treat it as frozen.

Allowed by default:

- fill in body text under existing headings
- remove unnecessary paragraphs
- fold useful content back into existing headings

Not allowed by default:

- adding same-level headings
- creating new `3.5+ / 4.5+ / 5.5+ / 6.3+` sections
- expanding the conclusion into many extra subsections

## 4. Rollback order

When the user asks to return to an earlier directory or reduce the body to a target length:

1. remove directory-level expansions
2. remove peripheral paragraphs
3. fold useful leftovers back into the original structure
4. only then adjust the density of the main chapters

## 5. Latest user instruction wins

If the user specifies:

- which directory version is best
- which additions are unnecessary
- the target body page count
- the TOC-format requirement
- whether new sections are allowed

then treat those latest instructions as highest priority.

## 6. TOC-only task rule

If the user provides a TOC screenshot, TOC sample, or says things like:

- `不要缩进`
- `目录居中`
- `目录到三级标题`

then treat it as a TOC-formatting task only.

Modify only TOC formatting rules, indentation, depth, or title presentation.

Do not silently rewrite thesis content, page plans, or directory structure when the user is only fixing the TOC.

## 7. Full-draft continuation unlock

Only allow explicit end-to-end continuation when both conditions are already satisfied:

- the body page count is confirmed
- the chapter / section / subsection directory is confirmed

If either one is missing, downgrade to:

- outline planning
- page planning
- requested chapter only
